# Cold Backlog — triggered & deferred chantiers

> **Big Bang reconciliation (2026-07-17, control-plane ADR 0047)** : the libre-ai org is frozen into the `libre-ai/libre-ai` monorepo. This file **survives as the meta trigger registry** (doctrines, product candidates, deferred chantiers) — but any trigger that fires now lands in the **monorepo work-package regime**, never in an archived legacy repo. The "Cross-layer locks" / "Product verticals" / "Substrate & factory" snapshot sections below describe the pre-Big-Bang repo states and are **frozen as trace**; the live product truth is the monorepo (`GOALS.md`, `STATUS.md`, `docs/transformation/G1-WORK-PACKAGES.md`). Row-level updates 2026-07-17: odysseus E22 is now partially consumed (the S2 recall envelope of `agent-conversational-memory-design.md`, Accepted R2); the orchestrator-adjacent rows feed `plans/orchestrator-lock-inputs.md`; documentation transfer feeds `plans/documentation-transfer-lock-inputs.md`; D10 is caduc (governed repos archived; governance scope = this repo).

Purpose: a single, thin index of the ecosystem's big chantiers so nothing is lost between waves and a lighter model can pick up "what is ripe to execute now". This is **pointers, not plans**: each row names the chantier, its real state, the trigger/blocker that gates it, and a stable anchor (ADR/contract/spec). A detailed `ecosystem.plan.v0.1` is written **at execution time against fresh state**, never stockpiled here (a fat plan rots as the code moves; a pointer does not).

Discipline (per the 2026-07-04 method arbitration):

- **Anchor to an ADR/contract, not to line numbers.** Volatile references are banned.
- **The trigger is the freshness gate.** Before executing a cold row, re-read `git log` + real state (agent-behavior §1); the row is a claim about the past.
- **Hot ≠ cold.** Hot chantiers live in `remaining-work.md` (the 2026-07 wave plan index). This file holds what is _deliberately deferred behind a trigger_, plus the cross-layer status snapshot so triage has one entry point.
- Prune rows when done or superseded.

State legend: **done** · **partial** · **stub** (specs/contracts only) · **not-started** · **cold** (deferred by design, trigger written).
