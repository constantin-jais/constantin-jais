# rumble-lm pilot reports

Local pilot reports are written here by `run-pilot.sh`.

Only commit a report after confirming:

- `meta.redaction.secrets_or_pii_included = false`;
- `meta.redaction.applied = false` for release evidence, or review is documented;
- no row data, prompt/source text, raw embeddings, DSNs, tokens, or personal data appear;
- all findings are triaged in `open-findings.md` / `false-positive-notes.md`.
